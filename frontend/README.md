# Cybersecurity Dashboard Frontend

## Overview
This is the frontend dashboard for the Institutional VAPT & Compliance Scanner project.

It provides a user interface for submitting authorized scan targets and displaying scan results from the backend.

## My Contribution
I developed the frontend dashboard using React and Vite.

My responsibilities include:
- Building the dashboard user interface.
- Creating the target input field and scan button.
- Connecting the frontend to the backend API.
- Displaying scan status and results.
- Handling loading states and errors.
- Designing a responsive interface.

## Technologies Used
- React
- JavaScript
- CSS
- Vite

## Project Structure
- `src/App.jsx` - Main dashboard component.
- `src/App.css` - Dashboard styling.
- `src/index.css` - Global styles.
- `src/main.jsx` - Application entry point.
- `index.html` - HTML entry page.
- `package.json` - Project dependencies and scripts.
- `vite.config.js` - Vite configuration.

## How to Run

1. Install Node.js and npm.
2. Open a terminal in the frontend directory.
3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL shown in the terminal.
