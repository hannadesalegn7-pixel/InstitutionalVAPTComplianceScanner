
# Institutional VAPT & Compliance Scanner

## About the Project
A web application designed to help Ethiopian institutions identify potential security weaknesses in authorized websites and networks, assess risks, and receive mitigation recommendations.

## Tech Stack
- Frontend: React and Tailwind CSS
- Backend: Python and FastAPI
- Scanning: Nmap
- Database: PostgreSQL

## Main Features
- Authorized network and port scanning
- Security findings dashboard
- Risk severity assessment
- Mitigation recommendations
- Security report generation
- Preliminary mapping to verified Ethiopian cybersecurity requirements
